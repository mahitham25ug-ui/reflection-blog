UNIT 2 - REFLECTION

Unit 2 was difficult as well as an interesting unit. The most interesting session of the unit was learning about images. This session helped us know more on how an image is represented in computers and how to calculate the memory required to store an image as well as videos. The idea that the range of colours having different intensity values which is represented with numbers was a new learning for me from the unit. And further, the labs helped me more on understanding the concept better. Through labs we also learned how different filters such as rotations, reflections and translations work on images.

We also learnt about number system and conversion from one number system to other in the unit. The four number systems we learned about was binary number system, decimal number system, octal number system and hexadecimal number system. I found number system conversions much easier than the other concepts that we learned in unit 2.

Another topic we learned was optimization and formal analysis which was about finding the best solution for a problem. This was also made clear through hands on lab practicals where we solved many problems to find its best solution. We also learned about the concept behind konigsberg bridges. This was also an interesting concept that we learned in this unit.

The last topic we learned in this unit was about modeling and abstraction. This was explained in class with so many examples which helped me understand about the concept. We learned about modeling, which is like creating a simplified model of the system which is to be built and abstraction which is about focus and filtering the main parts that will help us to solve problems.

Overall, this was a unit which was interesting as well as challenging to learn. We learned about so many new concepts which was earlier unexplored.
